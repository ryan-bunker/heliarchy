# Singularity

A real-time, massive multiplayer 2D space strategy game loosely inspired by *Stars!* (1995).

Set across a realistically scaled spiral galaxy, *Singularity* aims to combine classic 4X empire management—planetary colonization, mineral logistics, ship design, and fleet maneuvering—with continuous real-time pacing, realistic interstellar distances, and Newtonian propulsion mechanics.
